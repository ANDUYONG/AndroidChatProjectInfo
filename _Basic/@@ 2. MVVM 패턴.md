- Model View ViewModel
		Model: 데이터
		View: 사용자 ui
		ViewModel: 자료형
		
		대표적인 애플리케이션의 프로그래밍 패턴으로 데이터,
		사용자ui, 데이터를 담는 자료형을 독립적으로 분리해
		모듈화하여 좀 더 직관적인 프로그래밍을 지향하는 
		객체지향 프로그래밍 패턴이다.
			
> MVVM (Model-View-ViewModel) 패턴
	MVVM 패턴에 대한 님의 이해는 대체로 정확합니다. 
	하지만 몇 가지 개념을 좀 더 명확히 하면 좋을 것 같아요.

	Model: 데이터와 비즈니스 로직을 담당합니다. 
		데이터베이스 접근, 네트워크 통신 등 데이터와 관련된 
		모든 로직이 이 부분에 속합니다.

	View: 사용자에게 보이는 UI(User Interface)를 담당합니다.
		XML 레이아웃이나 위젯 등 화면을 구성하는 요소들이 여기에 
		해당합니다. View는 사용자의 액션을 ViewModel에 알리고, 
		ViewModel이 업데이트한 데이터를 화면에 반영하는 역할을 합니다.

	ViewModel: View를 위한 데이터와 상태를 관리하는 역할을 합니다.
	Model로부터 데이터를 받아와 가공하고, View가 사용할 수 있는
	형태로 만들어줍니다. ViewModel은 View에 대해 직접적으로 
	알지 못하므로, View와 Model 사이의 중간 다리 역할을 한다고 
	볼 수 있습니다.

	MVVM은 데이터를 독립적으로 분리하여 모듈화하는 것뿐만 아니라, 
	View와 Model의 의존성을 줄여 테스트와 유지보수를 쉽게 만드는 
	것이 가장 큰 장점입니다.
