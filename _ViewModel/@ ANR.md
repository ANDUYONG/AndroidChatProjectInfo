___

**ANR은 "Application Not Responding"의 약자**로, 안드로이드 운영체제가 **"애플리케이션이 응답하지 않는다"**고 판단할 때 발생하는 오류입니다. 사용자에게는 "앱이 응답하지 않습니다. 종료하시겠습니까?"와 같은 팝업 메시지로 나타나며, 이는 사용자 경험에 매우 치명적인 문제입니다.

그래서 메인 스레드가 지연되는 것을 막기위해 Repository단에서 백그라운드 스레드로 지연을 방지함.

### 백그라운드 스레드 사용은 `ViewModel`의 "역할"이 아닙니다.

시간이 오래 걸리는 작업(네트워크 요청, 데이터베이스 쿼리, 복잡한 계산 등)을 백그라운드 스레드에서 처리하는 것은 `ViewModel`의 직접적인 책임이 아닙니다. 이 역할은 보통 **Model 계층(예: `Repository`)** 또는 별도의 **비동기 처리 메커니즘** (Kotlin Coroutines, RxJava, Java Executor/Thread 등)에서 담당합니다.

`ViewModel`은 이러한 백그라운드 스레드에서 처리된 작업의 **결과를 받아서 UI 스레드의 `LiveData`를 통해 View에 전달하는 "조정자" 역할**을 합니다.
